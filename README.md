# school.net

A social network for my school, where students and teachers can share news, read announcements, and talk to each other in one safe place.

**Live demo (home page):** https://alex1510-uzb.github.io/school-net/

> **Project status:** Early development. The home page is finished. The app itself is still being planned and built.

## Why I'm building this

My school has no single place for announcements, class news, and student communication. Information is spread across different chats and often gets lost. school.net is my idea to fix that, and it is also my way to learn real app development.

## Run it locally

1. Download or clone the repository:
   ```bash
   git clone https://github.com/Alex1510-UZB/school-net.git
   ```
2. Open `index.html` in your browser.

No installation is needed for the home page.

## Privacy and safety

Because the users are school students, safety comes first:
- Only school members will be able to join.
- No personal data will be shown publicly.
- No card or password data will be stored in this repository.
- I will test with a small group of classmates and teachers before any wider release.
